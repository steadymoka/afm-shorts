Privacy Policy / 개인정보처리방침

Last updated: 2026-10-09

Who uses this app

afm-shorts is used only by its developer (steadymoka) to manage YouTube channels the developer owns. It does not sign in or collect data from any other person.

afm-shorts 는 개발자 본인만 본인 소유 유튜브 채널을 관리하는 데 씁니다. 다른 사람의 계정으로 로그인하거나 다른 사람의 정보를 모으지 않습니다.

Google user data accessed

  • YouTube Data API: upload videos and thumbnails, update video metadata and publish schedules, post comments, and read channel and video information — only for the developer's own channels.
  • YouTube Analytics API: read view and audience statistics for the developer's own channels.

How data is stored

OAuth tokens and the data read from the APIs are stored only on the developer's own computers. Nothing is sent to any other server, and nothing is sold, shared with, or transferred to third parties.

토큰과 API 로 읽은 데이터는 개발자 본인의 컴퓨터에만 저장합니다. 다른 서버로 보내지 않고, 제3자에게 팔거나 공유하지 않습니다.

Limited Use

afm-shorts's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file removes all stored credentials.
